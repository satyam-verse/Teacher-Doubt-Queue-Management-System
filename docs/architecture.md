# DoubtX AI — Comprehensive Architecture Specification

## 1. System Overview
**DoubtX AI** is an intelligent, real-time classroom queue and doubt resolution platform. It enhances technical classroom interactions by combining WebSocket-based live queue management with Google Gemini AI assistance, S3 attachment storage, and scalable AWS cloud infrastructure.

---

## 2. Component Architecture

### 2.1 Frontend Tier (Single Page Application)
- **Framework**: React 19 with Vite and TypeScript
- **Styling**: Tailwind CSS with shadcn/ui design tokens
- **Real-Time Layer**: Socket.IO client with automatic exponential backoff reconnection
- **HTTP Client**: Axios with request/response JWT interceptors
- **Key Modules**:
  - `Student Portal`: Interactive doubt submission, markdown code support, S3 direct attachment upload, dynamic wait time estimation, and Gemini AI instant debugging clues.
  - `Teacher Console`: 3-column Kanban live queue (Waiting, In Progress, Resolved), priority badges, 1-click claim, resolve modal, and Gemini AI pedagogical solution assistant.
  - `Analytics Bar`: Real-time queue counters (Waiting, In Progress, Resolved Today, Avg Wait).

### 2.2 Backend API Tier (Flask Application Factory)
- **Architecture**: Application Factory pattern (`create_app`) with modular Blueprints:
  - `legacy_bp`: Preserves exact legacy endpoints (`GET /` and `GET /add`).
  - `auth_bp`: JWT registration, login, token refresh, and RBAC (`@role_required`).
  - `doubts_bp`: CRUD, FIFO queue ranking, teacher claim, and status transitions.
  - `sessions_bp`: Classroom session creation and join codes.
  - `ai_bp`: Google Gemini API orchestration.
  - `uploads_bp`: AWS S3 presigned URL generation for secure, direct-to-S3 uploads.
- **Concurrency & WebSockets**: Flask-SocketIO running with Eventlet in production for high-throughput persistent WebSocket connections.

### 2.3 Database Tier (AWS RDS MySQL / SQLAlchemy ORM)
- **Engine**: MySQL 8.0 on AWS RDS (with local SQLite auto-fallback for local developer onboarding).
- **ORM**: SQLAlchemy with connection pool optimization:
  - `pool_size`: 10
  - `max_overflow`: 20
  - `pool_recycle`: 1800 seconds (prevents MySQL `wait_timeout` disconnects)
  - `pool_pre_ping`: True (verifies connection liveness before checkout)
- **Schema**:
  - `users`: ID, email, password hash (bcrypt), full name, role (student/teacher/admin), created_at.
  - `classroom_sessions`: ID, session_code (unique index), title, teacher_id, is_active.
  - `doubts`: ID, session_id, student_id, student_name (preserved), doubt (preserved), category, priority, status (QUEUED/IN_PROGRESS/RESOLVED), attachment_url, ai_hint, ai_suggested_solution, resolved_by_id, resolution_notes, timestamps.

### 2.4 AI Tier (Google Gemini API via `google-genai` SDK)
- **Model**: `gemini-2.5-flash` for sub-second analysis.
- **Capabilities**:
  - **Auto-Categorization**: Determines category (e.g. "React Hooks", "SQL Joins", "Recursion") and priority level.
  - **Deflection Hints**: Provides constructive hints to students waiting in queue without giving away the direct answer.
  - **Teacher Assistant**: Generates concise solution bullet points and corrected code snippets to accelerate teacher review.
  - **Graceful Fallback**: If Gemini API key is not supplied or throttled, falls back to heuristic keyword classification so the queue never halts.

### 2.5 Storage Tier (AWS S3)
- Direct-to-S3 uploads using presigned PUT URLs generated by the backend.
- Files bypass application server memory, reducing EC2 memory pressure and eliminating upload bandwidth bottlenecks.
